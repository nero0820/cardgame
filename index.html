CHROMA ORB

色つきの珠を載せて霊力を育てる、六色の対戦カードゲーム

残り-秒ターン -
遊び方
  • 勝ち方 相手のライフ(5)を0にした方の勝ちです。攻撃が通るたびに、ライフが1つ減ります。山札から引けなくなった人は、負けです。
  • 珠 珠には色があります。自分の番の始めに、自分の「珠デッキ」から1個をランダムにもらいます(最初の番は、先攻が3個(さらにその番だけ使える無色の珠が1個。ただし攻撃はできません)、後攻が4個)。持てる数に上限はありません。カードを使うと、そのコスト分の珠が、次の自分の番まで使えなくなります。 空き珠が足りないときは、場のユニットに載っている珠を外して払うこともできます(珠が0個になったユニットは消えます)。
  • 色とコスト そのカードと同じ色の珠は、空いていればコストの支払いに優先して使われます。同じ色の珠が空いていなくても、軽減はそのまま使えます(場の同じ色のユニット1体につき-1、最大-2)。また、ユニットの霊力が0になると倒れます。
  • ユニットとレベル ユニットを出すと、同じ色の珠が1個載ります。自分の番に、空いている好きな色の珠を載せて育てられ、載せた珠は外して使い回せます。載っている珠の数でレベルと霊力が決まります(必要な数はカードごとに違います)。レベルの効果は、そのカードと同じ色の珠がレベルの数以上載っているときだけ使えます。珠が0個になったユニットは消えて、黄泉(捨て札)に行きます。ユニットが倒れると、載っていた珠は手元に戻ります。
  • フェイズ 1回の番は、スタート(珠が戻り、疲労が解け、癒しが働く)→ドロー(1枚引く。学びが働く)→珠(抽選で珠を得る。実りと増珠が働く)→メイン(カードを出す、珠を載せ外しする)→アタック(攻撃する。鬨の声が働く)→エンド(呪詛と陣触れが働く)の順に進みます。スタート・ドロー・珠は自動で進み、メインから「アタックへ」を押すとアタックに入ります。アタックに入ると、カードを出したり珠を動かしたりはできません。
  • 攻撃 アタックフェイズに、出したターンから攻撃できます(ただし、先攻の最初の番だけは攻撃できません)。光っているユニットをタップして「攻撃」を押します。攻撃したユニットは疲労して、次の自分の番までブロックできません。
  • 霊力とブロック ユニットの強さは「霊力」の数値です。攻撃されたら、疲労していないユニット1体でブロックできます。ブロックしたユニットも疲労し(守り手は疲労していてもブロックできますが、相手の番に1回だけです)、次の自分の番まで攻撃もブロックもできなくなります。戦闘では霊力を比べて、低い方が倒れます。同じ数値なら、両方倒れます。ブロックしなければ、ライフが1つ減ります。
  • 妖術 手札の妖術は、相手の攻撃を受けたときだけ使えます。自分の番に珠を使い切らず、残しておきましょう。
  • 色 赤・青・緑・黄・紫・白の6色です。場に同じ色のユニットがいると、その色のカードのコストが1体につき1下がります(最大2)。
  • 用語 侵食: 攻撃時に、相手の山札を次の相手の番の始めに指定の枚数、黄泉へ送る / 奮起: 攻撃時、その戦闘の間だけ霊力が上がる / 威圧: 霊力が指定の数値以下のユニットは、ブロックできない / 回避: ブロックされない / 貫通: ブロックした相手を倒すと、ライフを1奪う / 守り手: 疲労していてもブロックできる(相手の番に1回だけ) / 刺撃: 攻撃時に、霊力が指定の数値以下のランダムな敵ユニットを倒す / 弱体: 攻撃時に、ランダムな敵ユニットの霊力を恒久的に-1000 / 引く: 攻撃時に1枚引く / 癒し: 自分の番の始めにライフ+1 / 群れ: 場の他の同色の味方1体ごとに霊力+1000 / 増珠: 自分の番の始めに、その番だけ珠を1つ多く使える / 強襲: ブロックされずに通ると、ライフをさらに1つ奪う / 氷結: 攻撃時に、ランダムな敵ユニット1体を疲労させる / 実り: 自分の番の始めに、自分の色の珠が1個増える / 純色: 載っている珠がすべて自分の色なら、霊力+2000 / 断末魔: 倒れる、または消えるとき、ランダムな敵ユニットの霊力を恒久的に下げる / 招集: 出したとき、白の「小兵」を1体出す / 統率: 場の他の同じ種族の味方すべての霊力+1000 / 珠砕き: 敵ユニットの珠を砕く。
  • 倒す効果 「霊力○以下を倒す」という呪文や妖術は、霊力がその数値を超える相手には効きません。
  • 種族と黄泉 ユニットには種族(鬼・獣・竜・武者・精霊・妖怪・神・人)があります。倒れたユニットや使い終えたカードは、黄泉(捨て札)に置かれます。黄泉のカードを使う呪文や効果があります。
  • 切札 切札はデッキとは別に最大8枚持ち、「切札」タブから出します。「場に鬼が2体以上」「ライフが2以下」「黄泉が5枚以上」といった条件を満たしたときだけ出せます。「火竜に重ねて出す」ような進化の切札は、元のユニットの上に重ねて、珠を引き継ぎます。
  • デッキ 30枚以上で、同じカードは3枚までです。上限の枚数はありません。珠デッキは最大10個で、色を自由に割り振ります。場は10枚、手札は10枚までです。
